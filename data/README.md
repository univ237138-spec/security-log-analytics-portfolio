# 공개용 데이터

[프로젝트 소개](../README.md) · [실행 가이드](../docs/08_실행가이드.md)

`demo/`에는 기업연계 프로젝트 제공 로그를 비식별 처리한 4개 데모 입력을 보관한다. 기업이 제공한 원본 CSV를 그대로 공개한 파일이 아니다. 원본과 비식별 대응표·인증정보·개인 문서는 포함하지 않는다.

| 파일 | 행 수 | 형식 |
|---|---:|---|
| [sshd_raw.csv](demo/sshd_raw.csv) | 1,364 | syslog |
| [nginx_raw.csv](demo/nginx_raw.csv) | 2,223 | combined |
| [sysmon_raw.csv](demo/sysmon_raw.csv) | 5,082 | XML |
| [audit_raw.csv](demo/audit_raw.csv) | 456 | JSON |

## 치환과 보존

- 계정은 역할을 나타내는 데모 별칭, 이메일은 `demo.example`, 고객 식별값은 데모 값으로 치환했다.
- 내부 주소와 서버 이름은 데모용 사설 대역·호스트 이름으로 바꿨다.
- 실제 공인 주소는 문서용 주소로 바꿨고 외부 목적지 도메인은 `.example`을 사용한다.
- 긴 식별값·GUID와 SSH 키 지문은 공개용 값으로 치환했다.
- 시간 순서·로그 형식·이벤트 종류·조인 관계를 보존하고 분석을 재실행했다. 키 지문의 치환값은 인증에 사용할 수 없고 실제 키 목록을 분석하는 용도가 아니다.
- 데이터 내부 시각은 관측용 값이며 오늘 날짜나 작업 일자와 다를 수 있다.

CSV는 UTF-8 BOM이며 원문에 개행·쉼표가 있으므로 텍스트 줄 수로 이벤트 수를 세지 않는다.

## 생성 경로

`run_pipeline.py` 실행 시 `data/01_raw`부터 `data/13_baseline_variants`까지 생성한다. 이 파일들은 재현 가능한 중간·최종 산출물이므로 Git에서 제외한다. 공개 확인용 핵심 결과는 [results](../results/README.md)에 보관한다.

비식별 데이터도 실제 고객이나 사람에 대한 사실·사건으로 해석하지 않는다. 데이터와 기업 제공 맥락의 재사용 조건은 코드의 공개 여부와 별개이며 별도의 범용 재배포 라이선스를 부여하지 않는다.
