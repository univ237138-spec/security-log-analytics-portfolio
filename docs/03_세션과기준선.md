# 세션과 과거 기준선

[프로젝트 소개](../README.md)

## 분석 단위

9,125개 이벤트를 사용자 업무 세션, 시스템 배경 활동, 세션 없는 외부 시도로 나눈다. 시스템 서비스 계정의 활동을 사용자 이벤트로 무조건 합치지 않는다.

SSH 인증 성공의 연결 키와 종료 기록을 기준으로 접속을 만들고, 동일한 IP·시간 구간의 웹 활동을 연결한다. 웹 전용 활동과 여러 SSH 접속의 묶음 조건을 별도 규칙으로 처리한다. 웹 이벤트를 묶는 간격은 관측 분포를 검토해 정했으며 통계적으로 독립적인 정상·이상 라벨은 아니다.

## 기준선

각 세션 **시작 전에 종료된 세션만** 과거 기록으로 선택한다.

| 수준 | 조건 |
|---|---|
| person | 본인 완료 과거 세션 5개 이상 |
| peer | 본인 기록이 부족하고 같은 주 작업 서버 그룹의 과거 세션 5개 이상 |
| global | 위 조건이 부족하고 전체 완료 과거 5개 이상 |
| none | 충분한 기록이 없어 비교를 보류 |

기준선은 시작 시각·접속 IP·사용 경로·명령·인증 방식·활동량·외부 연결 등의 평소 패턴과 비교값을 만든다. 서버 시스템 활동은 명령·파일·목적지 패턴을 별도로 집계한다.

## 지표와 경보는 다른 출력

처음 보는 값이나 분포 이탈은 신호다. 위험점수는 룰·행위 신호를 점수로 결합하고 자산 중요도와 연결 신뢰도를 반영한다. 경보는 점수 100 이상 또는 전술 3개 이상이라는 기준으로 정한다. 점수는 확률이 아니다.

각 세션의 과거 이력에 미래 완료 세션을 넣지 않았다는 검증과, 임계값·룰을 독립 평가 기간에서 검증했다는 주장은 다르다. 현재는 독립적인 시간 분리 성능 평가를 수행하지 않았다.

기본 파이프라인은 기존 V0 기준선이다. V1·V2는 [별도 비교 실험](05_기준선비교.md)이며 기본 결과를 변경하지 않는다.
