# 프로젝트와 개인 작업 범위

[프로젝트 소개](../README.md)

김현수의 개인 데이터 분석·구현 포트폴리오다. 기업연계 프로젝트에서 테이렌이 제공한 보안 로그를 출발점으로 사용한다. 기업의 로그 제공과 멘토링이라는 출처를 명시하고, 파싱·정규화부터 세션 분석·통계 검정·비교 실험·조사 화면까지의 개인 분석을 설명한다.

## 질문과 산출물

1. 서로 다른 로그를 공통 구조로 만들면서 정보 손실을 검증할 수 있는가?
2. 사용자·IP·프로세스·시간을 어떤 근거로 연결할 수 있는가?
3. 기준선과 룰 신호를 합쳐 조사할 활동을 설명할 수 있는가?
4. 개인·동료·전체 기준선 중 어느 대안이 이 데이터에 적합한가?

공개 버전 작성일은 2026-10-09다. 데이터 내부 이벤트 시각(2026-09-30~2026-10-16 UTC)은 작업 기간이나 실제 사건 발생일을 뜻하지 않는다. 제공 데이터는 합성 가능성이 있고 실제 운영 데이터로 확정하지 않는다.

## 분석과 제품 활용의 연결

산출물은 공격 확정 시스템이 아니라 조사 우선순위와 근거를 확인하는 분석 패키지다. 분석 결과에 부족한 로그를 명시하여 추가 수집 과제로 연결한다. 실제 처리 시간·오탐 비용·운영 효과는 측정하지 않았다.
