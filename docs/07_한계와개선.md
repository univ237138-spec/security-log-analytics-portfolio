## 우선순위

1. 독립적인 정상·이상 라벨과 시간 분리 평가를 구성한다.
2. V1을 후보 대안으로 비교하되 경보량·조사 비용·Precision@k를 측정한다.
3. 세션 활동량을 접속 수·기간으로 정규화하는 대안을 비교한다.
4. 저속 외부 로그인 시도를 1시간뿐 아니라 24시간·7일 창으로 검토한다.
5. 귀속 신뢰도와 로그 수집 공백을 지표에 반영한다.

위 항목은 구현 성과가 아닌 다음 작업이다. 현재 프로젝트의 경보 수·검정 결과·점수를 운영 정확도나 실제 사고 건수로 표현하지 않는다.
