## 환경

Python 3.14에서 검증한 패키지 버전은 [requirements.txt](../requirements.txt)에 고정했다. 모든 명령은 저장소 최상위에서 실행한다.

```bash
python -m venv .venv
# Windows PowerShell
.venv/Scripts/Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/run_pipeline.py
python -m streamlit run dashboard_v2/app.py
```

Snowflake 계정·기업 원본·인증키는 로컬 데모 재현에 필요하지 않다. 네트워크 연결은 패키지 설치에 필요하며 분석 자체는 로컬 CSV로 수행한다. 대시보드의 웹 글꼴은 외부 CDN을 이용하지만 CSV·인증정보를 전송하는 기능은 없다.

## 실행 순서

1. `data/demo` 4개 입력을 `data/01_raw` 작업 경로로 복사한다.
2. 파싱·정규화·원문 복원 검증.
3. 행위 분류·통합과 해당 검증.
4. 맥락 보강·엔티티 연결·세션화.
5. 과거 기준선·탐지·위험점수·조사.
6. 통계 검정·V0/V1/V2 비교.
7. 전체 무결성 검증·요약 결과·차트 생성.

원래의 [run_all.py](../scripts/run_all.py)는 파싱·초기 정규화까지만 실행한다. 포트폴리오의 전체 실행은 [run_pipeline.py](../scripts/run_pipeline.py)를 사용한다.

생성 CSV와 사고 카드는 Git에서 제외되며 재실행 시 덮어쓴다. 기본 기준선은 V0이고 비교 실험은 V1을 기본에 적용하지 않는다.

## 추가 검증

```bash
python scripts/99_verify_dashboard_v2.py
python scripts/verify_docs.py
```

대시보드 검증은 6개 페이지, 가림 표시, 카드 집계, 경보 목록, 세션별 점수 합계, 추정 귀속 안내, 0점 세션, 기간 필터, 참고 라벨을 검사한다.

## 화면 재촬영

```bash
python -m pip install -r requirements-dev.txt
python -m playwright install chromium
python -m streamlit run dashboard_v2/app.py --server.port 8513 --server.headless true
# 다른 터미널
python scripts/capture_screenshots.py
```

브라우저 검증·촬영은 로컬 서버의 공개 데모만 이용하며 사용자의 브라우저 프로필·로그인은 사용하지 않는다.

## 결과 파일

- [metrics.json](../results/metrics.json): 핵심 집계와 해석 범위.
- [validation_summary.json](../results/validation_summary.json): 자동 검사와 공개 입력 해시.
- [baseline_comparison.csv](../results/baseline_comparison.csv): 대안 비교.
- [statistical_tests.csv](../results/statistical_tests.csv): 주 검정 요약.
- [ui_validation.json](../results/ui_validation.json): 실제 브라우저 렌더·화면 집계 확인.

GitHub Actions는 공개 입력으로 전체 분석과 Streamlit 검사 및 문서 링크 검사를 실행한다. SQL은 별도의 Snowflake 사용 예시이며 이 자동 실행은 SQL 서버 결과까지 검증하지 않는다.
